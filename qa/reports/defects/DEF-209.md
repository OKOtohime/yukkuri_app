# DEF-209 上游单测依赖环境和平台：干净环境下失败 1 个，Windows 上再多失败 1~2 个

| 字段 | 值 |
| --- | --- |
| 严重程度 | S3（QR-MNT-01 为 S 级） |
| 关联需求 | QR-MNT-01 |
| 环境 | R1、W1；"干净环境"由 `qa/eval/mnt/run_upstream_clean.py` 构造（源码副本 + 空数据目录 + 临时 HOME + 无音频服务变量） |
| 版本 | b993c40 |
| 发现于 | WP-02，QR-MNT-01 执行；W1 上的两项即 WP-01 预备发现 P-02、P-03 |
| 可复现性 | 必现 |

## 复现步骤

```bash
python qa/eval/mnt/run_upstream_clean.py --tag R1 --out qa/reports/wp02          # R1
python qa/eval/mnt/run_upstream_clean.py --tag W1 --out C:\yk\qa\reports-wp02   # W1
YUKKURI_DATA_DIR=<有资源的数据目录> python -m pytest tests                         # 有资源
```

## 期望结果

QR-MNT-01：在没有模型、没有声线库、没有声卡的干净环境中运行上游单测，"全部通过，或需要真实资源的用例被显式跳过；不能出现 ERROR"。单测本身也不应依赖运行平台。

## 实际结果

| 环境 | 资源 | 结果 | 失败用例 |
| --- | --- | --- | --- |
| R1 | 干净 | 56 通过，1 失败 | ① |
| R1 | 有 | 57 通过 | — |
| W1 | 干净 | 55 通过，2 失败 | ①、② |
| W1 | 有 | 55 通过，2 失败 | ②、③ |

① `tests/test_aquestalk.py::test_dev_key_options_passed`：缺少声线库时 `AquesTalk1Engine` 抛 `FileNotFoundError: 未找到声线 'f1' 对应的 libAquesTalk.so 动态库`，用例没有按资源跳过。

② `tests/test_fixes.py::test_s6_get_default_data_dir`：断言写死了 POSIX 路径，`'C:\\tmp\\custom_yukkuri_data' != '/tmp/custom_yukkuri_data'`。产品在 Windows 上返回 `C:\tmp\...` 是正确的（`os.path.abspath`），问题在用例。

③ `tests/test_aquestalk.py::test_library_resolution`：断言库文件以 `.so` 结尾，Windows 上产品正确地返回 `.dll`（QA 用例 `test_fr_cfg_03_library_suffix_matches_platform` 在 W1 上通过），问题在用例。

## 初步分析

①缺少按资源跳过的条件（例如 `get_available_voices()` 为空时 `skipTest`）；②③的断言没有考虑平台差异。三者都是测试代码问题，不影响产品功能。
