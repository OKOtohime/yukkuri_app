# DEF-207 CLI 静默接受越界的 `--mic-gain` 和 `--output-gain`

| 字段 | 值 |
| --- | --- |
| 严重程度 | S3 |
| 关联需求 | BL-02、BL-03、FR-AUD-05、FR-OUT-07 |
| 环境 | R1、W1 |
| 版本 | b993c40 |
| 发现于 | WP-02，用例 `test_bl_02_cli_rejects_out_of_range_mic_gain[*]`、`test_bl_03_cli_rejects_out_of_range_output_gain[*]` |
| 可复现性 | 必现 |

## 复现步骤

`yukkuri --mic-gain 0`、`yukkuri --mic-gain -1`、`yukkuri --output-gain 10` 等。用例中将识别、合成等组件替换为桩，只观察 CLI 本身的处理。

## 期望结果

BL-02：麦克风增益有效范围 0.5~3.0；BL-03：输出增益有效范围 0.1~3.0。"CLI 遇越界值应拒绝或给出提示，不能静默钳位"（BL-01 的约定适用于 BL-02/03）。

## 实际结果

| 参数 | 取值 | 结果 |
| --- | --- | --- |
| `--mic-gain` | 0.49、3.01、0、-1、10 | 全部被接受，没有任何提示，正常启动 |
| `--output-gain` | 0.09、3.01、0、-1、10 | 同上 |

边界内的取值（0.5/1.0/3.0、0.1/1.0/3.0）按原值生效，结果正确。

可观察后果（代码推断，交 WP-05 在 L3 确认）：
- `--mic-gain 0`：初始增益为 0，送去识别的音频全为静音，程序"正常运行"但永远没有输出；
- `--mic-gain -1`：音频反相，可以工作，没有任何提示；
- `--output-gain 0` 或负数：被内部钳为 0，合成音全为静音；
- `--mic-gain 10`、`--output-gain 10`：严重削波。

## 初步分析

`yukkuri/cli.py:67-74` 两个参数只声明 `type=float`，没有范围检查；`:132-133` 原样写入 `AppConfig`。`MicrophoneStream.__init__` 不钳位（只有运行中的 `set_gain()` 钳到 ≥ 0.1，见 OBS-205）。`--speed`（BL-01）同样没有校验，归 WP-04/05。
