# DEF-208 短促环境噪声有 7.5% 会触发可听见的合成输出（阈值 5%）

| 字段 | 值 |
| --- | --- |
| 严重程度 | S3（S 级需求不满足） |
| 关联需求 | FR-VAD-06（阈值见 `docs/test-design/WP-02.md` 第 4 节评审结论 #2） |
| 环境 | R1，SenseVoice int8 + Silero VAD（CLI 默认参数） |
| 版本 | b993c40 |
| 发现于 | WP-02，用例 `test_fr_vad_06_transients_no_output` |
| 可复现性 | 必现（固定种子 20261007，结果确定） |

## 前置条件

模型就绪；本地有 MUSAN noise 语料（`qa/data/manifests/musan_noise.tsv`）。

## 复现步骤

200 条样本，每条为 0.5s 静音 + 事件 + 1.0s 静音（-60 dBFS 噪声底）：

- click：5ms 衰减脉冲 40 条；
- keyboard：1~4 次 30~80ms 噪声突发 60 条；
- musan：从 MUSAN noise 随机截取 0.1~0.5s，归一到 -20 dBFS RMS，100 条。

按 CLI 默认参数经 SileroVAD（800 样本块）→ 流水线的最短时长过滤（0.3s）→ SenseVoice → G2P，统计产生可发声音标的样本。

## 期望结果

FR-VAD-06："极短的非语音声响（咳嗽、键盘声、点击声）不触发合成输出"；评审确定误触发率 ≤ 5%。

## 实际结果

| 类别 | 样本数 | VAD 切出语音段 | 通过 0.3s 过滤 | 只有标点（无声） | 可听见的误触发 |
| --- | --- | --- | --- | --- | --- |
| click | 40 | 0 | 0 | 0 | 0 |
| keyboard | 60 | 0 | 0 | 0 | 0 |
| musan | 100 | 29 | 24 | 9 | **15** |
| 合计 | 200 | | | | **15（7.5%）** |

误触发的识别结果是 "Yeah."、"Okay."、"Oh."、"I."、"H."、"う。"、"哦。" 等，合成为 0.5~0.6s 的语音（例如 "Yeah." → `いえあは。`，峰值 30476）。15 条来自 15 个不同的 MUSAN 文件，不是个别文件里恰好含有人声。详细数据：`qa/reports/wp02/vad06_transients.json`。

"只有标点"的 9 条（识别为 "."）合成为 32ms 全零音频，听不到，不计入；是否违反 FR-G2P-13 交 WP-03 判定。评审时的口径是"产生非空音标"，按原口径为 24/200 = 12%，同样不通过（口径细化记录在设计文档第 4 节）。

## 初步分析

点击和键盘这类脉冲声 VAD 本身就能挡住。持续 0.3~0.5s 的宽带噪声（MUSAN）有约 1/4 被 VAD 判为语音并通过最短时长过滤，SenseVoice 对这类片段常输出 "Yeah"、"Okay" 一类的短词（ASR 幻听）。流水线没有对识别结果做置信度或"有效内容"判断，只要文本非空就合成。
