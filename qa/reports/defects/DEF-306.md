# DEF-306 分号、冒号、省略号不产生停顿（；：…… ; : 被静默丢弃）

| 字段 | 值 |
| --- | --- |
| 严重程度 | S3（建议：M 级需求 FR-G2P-11 部分不满足；只影响停顿，读音不丢） |
| 关联需求 | FR-G2P-11 |
| 环境 | R1、W1 |
| 版本 | b993c40 |
| 发现于 | WP-03，用例 `test_fr_g2p_11_punct_to_pause[*-；/：/……/…/;/:]`（三种 lang 各 6 条） |
| 可复现性 | 必现 |

## 复现步骤

| 输入 | 实际 | 期望 |
| --- | --- | --- |
| 你好；再见 | `にー/はお/ざい/じあん` | 你好 与 再见 之间有停顿（、或 。） |
| 注意：前方有人 | 无停顿 | 有停顿 |
| 等一下……好了 | 无停顿 | 有停顿 |
| hello; world | 无停顿 | 有停顿 |

## 期望结果

FR-G2P-11："文本中的标点转为语音停顿"。评审 Q3 确定必须产生停顿的符号：，。！？、；：……及 ASCII 的 , . ! ? ; :。引号、括号、破折号等可以忽略。

## 实际结果

，。！？、 , . ! ? 正常转为停顿；；：…… … ; : 被当作不可读符号删除，前后两句连读。

## 初步分析

`yukkuri/g2p/polyglot.py:79` 和 `:125` 的标点字符类只有 `[，。！？、?.,!/]`，`normalizer.normalize_punctuations` 也只处理这些符号。
