# DEF-301 音标中混入 AquesTalk 不接受的假名（づ、ぢ、ヴ、ヶ、・、单独小写假名、开头的 ー），整句合成失败、没有任何声音

| 字段 | 值 |
| --- | --- |
| 严重程度 | S2（建议：M 级需求 FR-G2P-11、QR-FUNC-07 不满足；日语常用词即可触发，整句静默丢失，无绕过办法） |
| 关联需求 | FR-G2P-11、FR-G2P-07、QR-FUNC-07；FR-TTS-07（失败后的提示，见"附带问题"） |
| 环境 | R1、W1（两平台结论相同；W1 的错误码形态不同，见下） |
| 版本 | b993c40 |
| 发现于 | WP-03，用例 `test_fr_g2p_11_output_synthesizable_known_cases[*]`、`test_fr_g2p_11_real_library_accepts_output[*]`、`test_qr_func_07_synthesizability`、`test_qr_func_07_real_transcripts` |
| 可复现性 | 必现 |

## 复现步骤

1. `--lang ja` 启动（或 GUI 选日语），说出或在文字播报中输入：`私もそれに気づきます`。
2. 观察日志。

也可以直接在 Python 中：

```python
from yukkuri.g2p import text_to_yukkuri_polyglot as g
g("私もそれに気づきます", "ja")   # 'わたし/もそれに/き/づきます'
g("3ヶ月", "ja")                  # 'サン/ヶ/がつ'
g("ジョージ・ワシントン", "ja")    # 'ジョージ・ワシントン'
```

## 期望结果

FR-G2P-11："任何符号都不导致合成失败（不可合成的符号被忽略）"。QR-FUNC-07：非空音标中 AquesTalk 返回 105/107 的比例 ≤ 0.1%。

## 实际结果

- 日志：`[AquesTalk 错误] 错误码 105: 音声記号列に未定義の読み記号が指定された`（R1）；W1 上为 `错误码 13: 未知错误`（见下）。该句没有任何合成输出。
- AquesTalk1 评价版（R1/W1，9 种声线结论相同）拒绝假名区块中的 52 个码位：单独出现的小写假名（ぁぃぅぇぉゃゅょゎゕゖ 及片假名对应）、ぢ づ ヂ ヅ、ゐ ゑ ヰ ヱ、ゔ ヴ ヷ～ヺ、・、ゝ ゞ ヽ ヾ、゛゜ 等；ー 出现在开头、停顿符或 っ 之后时返回 102。实测表：`qa/data/aquestalk_alphabet.json`。
- G2P 的清洗规则放行整个假名区块，这些字符原样进入音标：
  - kakasi 的读音本身含 ぢ/づ：鼻血 → `はなぢ`、近づく → `きん/づく`、気づかう、基盤づくり；
  - 日文文本中的片假名外来语和符号原样保留：ヴァイオリン、カヴァ、ヴィトーリア、ジョージ・ワシントン、主観的・客観的、3ヶ月、いすゞ、あぁ。
- QR-FUNC-07 量化（10,130 条，`qa/reports/wp03/qr_func_07_{R1,W1}.json`）：

| 子集 | 非空音标 | 记号类失败（105/107） | 比例 |
| --- | --- | --- | --- |
| A 真实转写文本（AISHELL-1、LibriSpeech、CV-ja、混说脚本） | 1,630 | 12 | **0.74%** |
| 　其中 CV-ja（日语） | 500 | 12 | **2.4%** |
| B 结构化随机 | 5,963 | 2,876 | 48.2% |
| C 字符级模糊 | 2,465 | 1,903 | 77.2% |
| **合计** | **10,058** | **4,791** | **47.6%**（阈值 0.1%） |

  B/C 的比例受生成器权重影响（假名片段按整个区块均匀取字），只说明问题类别；**仅真实日语转写文本就有 2.4% 的句子完全无声**，已足以判定不满足。没有崩溃，G2P 没有异常。

## 附带问题（Windows，交 WP-04 在 FR-TTS-07 中判定）

W1 的评价版 DLL 遇到未定义记号时，不返回 105，而是把该记号的 **1 起算字节位置**写入错误码（`づ` → 1，`あづ` → 4，`私もそれに気づきます` → 28）；小写假名单独出现时仍返回 105。产品按错误码查表，因此 Windows 上的提示是 `错误码 28: 未知错误`，用户看不出原因。W1 上 4,791 条记号类失败中 3,192 条以位置值返回。

## 初步分析

- `yukkuri/g2p/normalizer.py:51` 的白名单 `[^぀-ゟ゠-ヿ、。？?ー/']` 按 Unicode 区块放行，而不是按 AquesTalk 的音记号表放行。
- 可行的处理方向（供参考）：ぢ/づ → じ/ず，ヴ+小写 → ば行，ヶ → か/が（或在数词后读 か），・ → 停顿或删除，孤立小写假名 → 对应大写假名，开头/停顿后的 ー 删除；其余不在音记号表中的字符删除。
