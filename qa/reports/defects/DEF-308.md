# DEF-308 中文模式下阿拉伯数字 2 读作 `あー`（a），与汉字「二」的 `あーる`（er）不一致

| 字段 | 值 |
| --- | --- |
| 严重程度 | S4（测试负责人裁定） |
| 关联需求 | FR-G2P-09；QR-FUNC-08 |
| 环境 | R1、W1 |
| 版本 | b993c40 |
| 发现于 | WP-03，用例 `test_fr_g2p_09_digit_two_matches_numeral[zh-二]`；黄金集 N001、N004、N010 |
| 可复现性 | 必现 |

## 复现步骤

```python
from yukkuri.g2p import text_to_yukkuri_polyglot as g
g("2", "zh")    # 'あー'
g("二", "zh")   # 'あーる'
g("2026年", "zh")  # 'あー/りん/あー/りう/にあん'
```

## 期望结果

FR-G2P-09："数字按当前语种读出"。中文中 2 读 èr，与汉字「二」相同（映射表中 er → `あーる`）。

## 实际结果

数字 2 读 `あー`，丢失儿化韵，听起来是 a。同一个数在「2」和「二」两种写法下读法不同。其余 9 个数字（0、1、3~9）的读法都与对应汉字的拼音映射一致。SenseVoice 开启 ITN，数量、年份、时间多以阿拉伯数字出现（如「2026年」「12点」）。

## 初步分析

`yukkuri/g2p/normalizer.py:8` 中 `DIGIT_CN['2'] = 'あー'`，而 `PINYIN_MAP['er'] = 'あーる'`。
