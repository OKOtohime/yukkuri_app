# DEF-205 只导入单个 AquesTalk 库文件后，9 种声线全部被判为"已安装"

| 字段 | 值 |
| --- | --- |
| 严重程度 | S3（建议：只在"单个 .dll/.so 导入"方式下出现；导入官方多声线包不受影响） |
| 关联需求 | FR-CFG-03、FR-TTS-02、FR-TTS-03、FR-MDL-05、FR-MDL-07 |
| 环境 | R1、W1（L1 用例两个平台都复现） |
| 版本 | b993c40 |
| 发现于 | WP-02，用例 `test_fr_cfg_03_voice_libraries_not_aliased_single_file_import` |
| 可复现性 | 必现 |

## 复现步骤

1. 空数据目录中执行 `python setup_models.py --aquestalk /path/to/libAquesTalk.so`（Windows：`AquesTalk.dll`），这是 FR-MDL-05 列出的导入方式之一。
2. `python setup_models.py --check`；或打开 GUI 查看声线下拉框。

## 期望结果

- FR-TTS-02：GUI 声线列表只显示已安装的声线。
- FR-TTS-03：切换到未安装的声线时提示失败，原声线保持不变。

## 实际结果

`--check` 报告"已就绪: 9 种声线"，`get_available_voices()` 返回全部 9 种。选择 m1、jgr 等任何声线都"切换成功"，实际全部用同一个库（f1）合成，用户得不到任何提示。

## 初步分析

- `yukkuri/model_downloader.py` `install_aquestalk_from_archive()` 对单个库文件同时复制到 `libs/aquestalk/lib64/` 和 `libs/aquestalk/`。
- `yukkuri/config.py:184-192` `find_aquestalk_library()` 对**每一种**声线都会搜索不带声线子目录的 `libs/aquestalk/` 和 `libs/`，所以任何声线都能解析到这份 f1 库。
