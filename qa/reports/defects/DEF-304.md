# DEF-304 含元音字母或超过 3 个字母的英文缩写被当作单词音译（USB → うすぶ，HTTP → はととぷ）

| 字段 | 值 |
| --- | --- |
| 严重程度 | S3（建议：M 级需求 FR-G2P-05 部分不满足；词表内的 CPU/GPU/PC 等正确） |
| 关联需求 | FR-G2P-05；QR-FUNC-08 |
| 环境 | R1、W1 |
| 版本 | b993c40 |
| 发现于 | WP-03，用例 `test_fr_g2p_05_acronyms[USB/API/OBS/DIY/HTTP/HTML]`；黄金集 en-缩写 类 10/15 |
| 可复现性 | 必现 |

## 复现步骤

任一语种下转换：

| 输入 | 实际 | 期望（逐字母） |
| --- | --- | --- |
| USB | `うすぶ` | ゆー/えす/びー |
| API | `あぴ` | えー/ぴー/あい |
| OBS | `おぶす` | おー/びー/えす |
| DIY | `でぃい` | でぃー/あい/わい |
| HTTP | `はととぷ` | えいち/てぃー/てぃー/ぴー |
| HTML | 音译 | えいち/てぃー/えむ/える |

## 期望结果

FR-G2P-05："英文缩写逐字母读出，例如 `CPU` → `しー/ぴー/ゆー`"。评审 Q4：全大写的 2~5 字母缩写按字母读（NASA 这类读作单词的除外）。

## 实际结果

只有"≤ 3 个字母且不含 a/e/i/o/u"的缩写逐字母读；含元音或 4 个字母以上的全大写缩写走音节音译。另一方面，同一规则把**小写的普通短词**也拼成字母：`my` → `えむ/わい`、`by` → `びー/わい`（见观察项 OBS-304）。

## 初步分析

`yukkuri/g2p/polyglot.py:27` 先 `lower()`，大小写信息丢失；`:38` 的判断 `len(w) <= 3 and not any(v in w for v in 'aeiou')` 既漏掉含元音的缩写，又误伤只含 y 的单词。可考虑用原文是否全大写判定缩写。
