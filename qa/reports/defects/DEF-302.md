# DEF-302 日语助词纠偏对真正的助词从不生效，反而把名词 葉/歯/屁 改读成 わ/え

| 字段 | 值 |
| --- | --- |
| 严重程度 | S3（建议：S 级需求 FR-G2P-08 不满足） |
| 关联需求 | FR-G2P-08、BL-08；QR-FUNC-08 |
| 环境 | R1、W1 |
| 版本 | b993c40 |
| 发现于 | WP-03，用例 `test_fr_g2p_08_particles[*]`、`test_fr_g2p_08_non_particles_unchanged[*]`；黄金集 ja-助词 类 1/10 |
| 可复现性 | 必现 |

## 复现步骤

`lang=ja` 下转换以下文本（CLI/GUI 日志中的 `[油库里音标]`）：

| 输入 | 实际 | 期望（BL-08） |
| --- | --- | --- |
| 私は | `わたし/は` | わたしわ |
| これは本です | `これは/ほん/です` | これわほんです |
| 東京へ行きます | `とうきょう/へ/ぎょう/きます` | とうきょうえいきます |
| こんにちは | `こんにちは` | こんにちわ |
| 葉 | `わ` | は |
| 歯が痛い | `わ/が/つう/い` | はがいたい |
| 屁 | `え` | へ |

## 期望结果

BL-08（已评审）："作为助词出现的 は/へ 读作 わ/え，**包括 ASR 输出中汉字后紧跟的假名助词**（如「私は」）"。不是助词的 は/へ 不应改读。

## 实际结果

- 真正的助词全部原样读成 ha/he；
- 单独成段的汉字名词，只要 kakasi 读音恰好是 は/へ，就被改读成 わ/え（葉、歯 → わ，屁 → え）。

## 初步分析

`yukkuri/g2p/polyglot.py:79` 的分词正则把汉字串和假名串切成不同片段。纠偏逻辑（`:112-116`）只在**汉字片段**的 kakasi 结果上判断 `orig == 'は' or hira == 'は'`：汉字片段的 orig 不可能是假名 は，所以只有读音整体等于 は/へ 的单字名词会命中；助词 は/へ 在假名片段里，走 `:103` 原样保留，永远不会被纠偏。
