## 1. 范围说明

### 1.1 被测接口与可观察结果

| 接口 | 可观察结果 |
| --- | --- |
| CLI `yukkuri --voice/--speed/--dev-key/--usr-key` | 参数是否被接受、退出码、stderr 提示；引擎收到的声线、语速、密钥（经桩库记录） |
| `AquesTalk1Engine`（流水线和 GUI 都直接使用） | `synthesize` 的返回（WAV 或 None）、stderr 提示；`set_voice` 的返回与之后的输出声线 |
| GUI 回调 `_refresh_voices` / `_on_voice_changed` / `_on_speed_changed` | 声线下拉框的选项、日志区文字、流水线配置（不启动 Tk，用替身对象调用未绑定方法） |
| `setup_models.py`（`--check`、下载、`--aquestalk`） | 终端输出、退出码、数据目录中的文件；`--check` 结论；之后程序能否加载 |
| `setup_models.sh` | 同上（与 `setup_models.py` 对比） |
| `model_downloader` 的下载与导入函数（GUI 模型管理也调用它们） | 文件系统上的写入位置与内容 |

### 1.2 测试替身

- **AquesTalk 桩库**（`qa/stubs/aqtk_stub.c`）：导出与真库同名的 5 个符号（`AquesTalk_Synthe`、`AquesTalk_Synthe_Utf8`、`AquesTalk_FreeWave`、`AquesTalk_SetDevKey`、`AquesTalk_SetUsrKey`）。Linux 用 gcc 编为 `.so`，Windows 用 llvm-mingw 交叉编译为 `.dll`。行为：
  - 返回合法的 8 kHz 16 bit 单声道 WAV；采样数 = 基准 × 100 / speed，数据区开头写入**本库所在目录名**（即声线名）和收到的 speed，供用例识别"哪个声线、什么语速"合成了这一句；
  - 音标以 `#E<n>` 开头时返回 NULL 并写回错误码 n（模拟 100~107、204 以及 Windows 评价版的"字节位置"错误码）；
  - `SetDevKey/SetUsrKey`：只有 `VALID-DEV` / `VALID-USR` 返回 0，其他返回 1；
  - 每次调用追加一行到环境变量 `QA_STUB_LOG` 指定的文件（`SetDevKey <key>`、`Synthe <utf8|sjis> <speed> <hex>`、`FreeWave`），用于判定密钥来源、编码接口、内存释放；
  - 编译开关 `-DNO_UTF8` 生成不导出 `AquesTalk_Synthe_Utf8` 的变体，覆盖 IMPL-14 的 Shift-JIS 分支（真库两平台都导出 UTF-8 接口，WP-03 中该分支未被执行）。
- **本地模型服务**（`qa/harness/model_server.py`）：线程内 HTTP 服务，提供与真实目录结构一致的**假模型**（小体积 `silero_vad.onnx`、SenseVoice `tar.bz2`、Vosk `zip`），并按路径注入故障：404、连接拒绝、带/不带 `Content-Length` 的中途断开、限速、首字节后停滞。
  - 被测脚本在子进程中运行。重定向方式：测试包装脚本 `qa/harness/run_setup_models.py` 在导入后把 `model_downloader.VAD_URL / SENSEVOICE_URL / VOSK_URLS` 改为本地地址，再执行 `setup_models.main()`。只改测试进程内存中的常量，不改产品文件。
  - `setup_models.sh` 使用 `curl`，用 PATH 中的 `curl` 替身（按 URL 映射到本地文件，也能模拟失败）。
- **磁盘空间不足**：Linux 用 `unshare -rm` 在用户命名空间里挂载 1 MB tmpfs 作数据目录，得到真实的 ENOSPC（已在 R1 验证可用，不需要 root）。Windows 不做（见 Q6）。

## 2. 测试设计

### 2.1 FR-TTS-05 密钥来源决策表

条件：CLI 参数（有/无）× 系统环境变量（有/无）× `.env`（有/无），DevKey 与 UsrKey 各做一遍，共 16 列；另加"CLI 传空串"列。动作：桩库记录的 `SetDevKey/SetUsrKey` 实参。期望：CLI > 环境变量 > `.env`；都没有时不调用。入口：CLI（子进程，`--voice f1`，数据目录只放桩库，引擎初始化后因缺模型以退出码 1 结束，正好在 ASR 之前）；GUI（`AppConfig()` 在同样的环境与工作目录下构造，并静态核对 GUI 启动代码把 `config.dev_key/usr_key` 传给引擎）。
